# NASai Brand Identity

## Core idea

NASai is represented by a compact, friendly coding-agent character: a soft asymmetric body, a floating signal dot, calm eyes, and a confident smile. The identity should feel warm and intelligent without becoming childish or resembling a generic robot.

## Asset system

| Asset                              | Use                                                                            |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `assets/brand/nasai-mascot.png`    | Full 3D character for onboarding, empty states, assistant presence, and motion |
| `assets/brand/nasai-mark-mono.svg` | Single-color category icon, navigation, status chips, and small sizes          |
| `assets/brand/nasai-app-icon.png`  | Master square application icon                                                 |
| `assets/NASai.ico`                 | Generated multi-resolution Windows icon                                        |

The single-color mark uses `currentColor`. It may appear white, teal, or another category color, but its geometry must not change between categories.

## Palette

- Agent teal: `#41D9B0`
- Agent mint: `#9AF5D4`
- Signal amber: `#FFC857`
- Deep navy: `#071019`
- Surface navy: `#14243A`
- Cloud white: `#EDFDF8`

## Motion

The mascot may float subtly and the signal dot may pulse. Motion must be calm, functional, and disabled when the operating system requests reduced motion. Avoid constant bouncing, exaggerated squash, or decorative animation that competes with the task.

## Restrictions

- Do not replace the mark with a generic robot, speech bubble, or letterform.
- Do not use the detailed 3D mascot as a 16 px navigation glyph; use the mono mark.
- Do not distort, recolor individual facial elements, add text inside the icon, or place the mascot on a busy background.
- The linked Dribbble work and supplied screenshot are mood references only; NASai assets must remain original.
